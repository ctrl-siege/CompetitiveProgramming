## Machine Problem 2

Create a program that runs the Fibonacci sequence (0, 1, 1, 2, 3, 5...)

Input: A single integer N, representing the number to search for in the Fibonacci sequence.

Output: If N exists in the Fibonacci sequence, print its position. Otherwise, print Does not exist.

Constraints:
- 0 ≤ N ≤ 10⁹
- Time Limit: 1 second
- Memory Limit: 256 MB

Sample input:
```
8
```

Sample output:
```
6
```
